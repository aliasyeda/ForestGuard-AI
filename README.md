# ForestGuard-AI

Churn Prediction Model: An AI/ML model that predicts whether a customer is likely to stop using a product or service. It analyzes customer behavior, usage patterns, and other relevant factors to identify customers who are at risk of leaving, helping businesses take early action to improve customer retention.


This repository showcases the complete workflow of the Churn Prediction Model, covering different stages such as data preprocessing 🧼, exploratory data analysis, feature engineering, and model building. It also contains the different datasets and processed files used throughout the project, including train.csv, test.csv, X_processed.csv, and other supporting CSV files, making the entire machine learning pipeline easy to follow and understand.
